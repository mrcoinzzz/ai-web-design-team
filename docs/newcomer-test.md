# A short newcomer test

This is a ready-to-run evaluation plan, not a recorded user study. Use an authorized participant and a disposable copy of the fictional example. Do not ask them to provide credentials or real customer data.

**Task:** “Use this team to identify the most useful improvements to the Clearfile homepage. Keep the website unchanged, then explain which suggestion you would try first.” Start them at the README rather than giving installation steps verbally.

Observe whether they can find setup instructions, invoke the skill, supply the intended evidence, recognize Alex's combined response, and tell review-only work from implementation. Record where they hesitate, need assistance, misunderstand a term, or mistake simulated behavior for a real integration. Do not coach them through each click; note assistance when it is necessary.

Then ask: “How would you ask for help with only the layout?” and “What could the team verify, and what couldn't it?” These probe whether names and capability explanations actually help.

Record the host/version, available tools, task, completion, assistance, confusing wording, and one focused improvement to try. Use anonymous participant labels. Share only consented, sanitized findings. Avoid claiming broad usability from one participant or treating this plan as a completed test.
